# Driver App (Login, Ride Requests, Ride Details, On Trip, Earnings, Profile)

## Run in VS Code (two terminals)
Terminal 1:
    cd backend && npm install && npm start      # http://localhost:4000
Terminal 2:
    cd frontend && npm install && npm run dev   # http://localhost:5173

Demo login:  driver@demo.com  /  driver123
Data is in-memory (resets when the backend restarts). Swap `db` in server.js for MongoDB/Postgres later.
